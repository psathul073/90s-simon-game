# 90s Simon Game
Welcome to the 90s Simon Game! This project is a nostalgic throwback to the classic memory game, built with HTML, CSS, and JavaScript. Enjoy a user-friendly interface, complete with dark mode and engaging sound effects.

## Features
- **Classic Gameplay:** Follow the light and sound patterns to test your memory.
- **Dark Mode:** Easily switch to a darker theme for comfortable gameplay in low-light settings.
- **Sound Effects:** Experience immersive audio that enhances gameplay.
- **User-Friendly Interface:** Simple and intuitive design suitable for all ages.
## Demo

Check out the live demo [here](https://psathul073.github.io/90s-simon-game/).

## Getting Started
### Prerequisites
A web browser (latest versions of Chrome, Firefox, Safari, or Edge)
### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/90s-simon-game.git
2. Navigate to the project directory:
   ```bash
   cd 90s-simon-game
3. Open `index.html` in your web browser.
## How to Play
1. Start the game by clicking the "Start" button.
2. Watch and listen to the sequence of lights and sounds.
3. Repeat the sequence by clicking the corresponding buttons.
4. Challenge yourself to keep going as the sequences become longer!
## Customization
You can customize the game by editing the styles in styles.css or the game logic in script.js.
